# Employee Salary Analysis 🐍

## 📌 About the Project

This is my third task at Veda Technology. In this project, I created a Python program to analyze employee salaries and calculate the total, average, highest, and lowest salary.

## 🎯 Objective

To practice numerical data processing using Python.

## 🛠️ Tools Used

* Python
* Jupyter Notebook

## 💻 Concepts Used

* Python Lists
* `sum()` – To calculate the total salary.
* `len()` – To count the number of salaries.
* `max()` – To find the highest salary.
* `min()` – To find the lowest salary.

## 📊 Sample Data

`[25000, 32000, 28000, 45000, 30000]`

## 📈 Results

* **Total Salary:** ₹160,000
* **Average Salary:** ₹32,000
* **Highest Salary:** ₹45,000
* **Lowest Salary:** ₹25,000

## 📚 Learning Outcome

Through this task, I learned how to store numerical data in a list, use Python's built-in functions, calculate salary statistics, and compare results with the original data.

## ✅ Conclusion

This project helped me improve my basic Python programming skills and understand numerical data processing through practical learning.

**Note:** The salary values used in this project are sample data for educational purposes.
